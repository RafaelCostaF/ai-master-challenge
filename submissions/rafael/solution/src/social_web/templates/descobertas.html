Como usar

Descobertas confirmadas podem virar decisão. As que se repetiram nos 2 anos formam a fila de testes A/B. As pistas devem ser acompanhadas mês a mês no painel Explorar. No conjunto, o número de padrões que se repetem é parecido com o que o acaso produziria, então cada um é uma hipótese até ser testado.
