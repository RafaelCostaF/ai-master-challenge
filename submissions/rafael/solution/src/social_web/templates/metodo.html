Transparência

Como chegamos lá

O objetivo foi separar o que realmente funciona do que só parece funcionar. Com {{ d.meta.posts | num }} posts, sempre aparece algum grupo "melhor" por puro acaso. Por isso cada conclusão passou por cinco checagens.

As 5 checagens

  1. Comparar parecido com parecido. Patrocinado contra orgânico só dentro da mesma plataforma, formato, tema e tamanho de creator.
  2. Descontar a sorte. Quando testamos milhares de combinações, algumas parecem boas por acaso. Ajustamos para isso: só conta o que sobra depois do desconto.
  3. Ver se teria sido possível enxergar. Para cada "não faz diferença", calculamos o menor efeito que os dados conseguiriam detectar. Aqui, diferenças de ~{{ d.dados.mde_views | num(1) }} views (0,03%) já apareceriam.
  4. Repetir no tempo. Um padrão só ganha força se aparecer no 1º ano e de novo no 2º.
  5. Provar que o método funciona. Plantamos de propósito efeitos de 2% a 10% em cópias dos dados. Os métodos encontraram todos.

Limitações

  • Dados simulados: as conclusões descrevem este conjunto de dados, não o mercado.
  • Sem preços: custos de patrocínio e produção são premissas, e devem ser trocados pelos valores reais.
  • Identificação de creators: o mesmo creator aparece com nomes e números de seguidores diferentes. A "duração" vale para todos os formatos, inclusive imagem.
  • Correlação não é causa: antes de mudar a operação, confirme com teste A/B.
